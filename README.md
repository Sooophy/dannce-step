# Dannce-step
This is the GitHub Repo for "Motor dysfunction landscapes for deep preclinical stroke phenotyping and enhanced therapeutic screens".

# Installation
Please refer to the official [DANNCE repo](https://github.com/spoonsso/dannce) for installation of the dannce environment. 

After having the DANNCE prediction ready, you can choose to analyze designed features or unsupervised behavior profiles. For designed features, please refer to `designed_features` for mid-rearing, high-rearing and velocity analysis. For unsupervised behavior profiles, please refer to `tsne` folder and follow the `README.md` inside the subfolder.
